Generator	and	Every	Screen	Shell
First,	write	a	small	JavaScript	mock-data	function	that	returns	fake
messages	matching	the	exact	shapes	above,	with	values	that	change
every	2	seconds	(simulate	an	escalating	call:	SVI	climbing	from	20	to
85	over	ten	fake	updates).	Use	this	to	drive	every	UI	component	you
build	in	this	entire	document	--	you	do	not	need	any	real	backend
running	at	any	point	until	Phase	3.
Build	these	screens	as	React	components,	each	rendering	from	your
mock	data	generator:
1.	
Caller-facing	IVR-sim	UI
	
--	a	phone-style	interface:	header	text
"NHAA	14566	--	incoming",	a	dropdown	for	language	(Hindi	/
English	/	Hinglish),	a	green	"Receive	call"	button,	a	call	timer	that
counts	up,	a	placeholder	waveform	(a	simple	animated	CSS	bar
chart	is	enough),	and	a	pre-call	consent	screen	with	three
checkboxes	labeled	exactly:	"I	agree	to	recording",	"I	agree	the	AI
can	look	at	it",	"I	agree	to	help	improve	the	system	later	(you	can
say	no	to	this	one)",	plus	buttons	"Decline	all"	and	"Accept
selected".
2.	
Agent	console
	
--	a	live	transcript	text	area	that	appends	new	text
every	mock	update,	eight	labeled	horizontal	progress	bars	(one	per
dimension,	label	them	exactly:	Acute	Distress,	Depression,	Self-
Harm	Risk,	Fear	of	Retaliation,	Intimidation,	Dissociation,	Social
Isolation,	Chronic	Trauma),	a	large	badge	showing	the	SVI	number
colored	green	(0-25)	/	yellow	(26-50)	/	orange	(51-75)	/	red	(76-

Legal	Aid,	Police	Intervention,	Witness	Protection,	Emergency
Escalation),	the	last	three	visually	greyed	out	with	the	text
"REQUIRES	SENIOR	APPROVAL"	until	their	mock	state	says
otherwise.
